# From a brief to a finished deck

## Identify the task

| Request | First pass |
| --- | --- |
| Create a deck | Gather the purpose, audience, topic, materials, preferred length, delivery conditions and outputs. |
| Convert PowerPoint | Inventory the ordered content, notes, media, charts and hidden slides. Confirm scope from the request. Convert legacy files through a presentation application. |
| Improve a deck | Render the approved version. Identify protected slides and separate requested changes in copy, imagery, design or export. |

Use context already available. If an important choice is missing, ask once about the variables that decide the result. Typical choices include live talk or reading deck, short or extended, brand direction and output formats. For a clear brief, proceed using its direction.

## Establish the content density

- **Speaker-led.** Use a single main thought, large type and one useful illustration or figure. Leave explanation for the speaker where the delivery allows it. Begin at one to three short bullets if a list is the best structure.
- **Reading-first.** Preserve the context and interpretation necessary to understand the file independently. Use labeled tables, figure annotations and groups of related points. Begin around four to eight short bullets or four to six small regions only when the reading order is clear. Split long material ahead of shrinking the type.
- **Teaching or process.** Use the density appropriate to each moment. Give definitions and stages enough space, show an example with relevant visuals, connect activity to learning and decision, and close with the takeaway.

## Work with the materials

Review the actual images, tables, clips and sketches. Identify the subject, action, quality, aspect ratio, usable crop, and which concept it proves. Plan story and visual evidence together. Use permissioned local files where available. Keep important faces, hands, artifacts and numbers in frame. Check every stage has purposeful material.

Every slide needs a visual. If a meaningful image is missing, find one on the web ([web-visuals.md](web-visuals.md)) or use the available image tools, and record its source. Draw exact diagrams and charts from the source data. Even a typographic brief gives each slide a picture, diagram, chart or large graphic figure. Never use illustrative media to imply an undocumented event.

## Discover the design visually

Use the [original library](original-workflow.md), the [Ninna catalog](style-index.md) or a custom design to select by use, audience and tone. Aim for three live cover previews when the direction is open. Include an appropriate familiar direction, an expressive one and a custom option or another sharply differentiated treatment. For a clear brand, selected style or narrow revision, use it directly.

Use the same actual title, story or image, and relevant approved logo across the options. Make each the true opening slide and label the alternatives outside the canvas. Open the previews using the available preview surface and link them for comparison. If the choice is delegated, choose the one that fits the venue and story. When the user chooses, expand that direction into section, image-and-text, comparison, exact diagram, decision and closing compositions. A useful preview defines a system the whole deck can use. When the user separately supplies a template collection and requests a specific original design, consult its index and selected design as project inputs. Keep applicable notices with any reused materials.

## Convert and revise

For conversion, carry over the original slide order, text, captions, diagrams, photos, speaker notes and appendix. The source layout is the visual reference by default. When asked for a creative redesign, preserve facts and structure unless the user delegates a story change. Verify chart units and categories, cropped images, logos, embedded media and notes against the original. Render complex diagrams in the source application when extraction cannot reconstruct them accurately.

For a revision, check the physical room on the slide before adding text or a photo. Redesign the group or split it only within the authorized scope. Check overlap and clipping in rendered images as well as DOM measurements. Keep approved layout, text and numbering where required.

## Deliver and share

Deliver the formats asked for and validate each one. In a browser handoff, include the main navigation and how to open any editing controls if enabled. Add a live URL only when requested, using an available approved host and a verified link. Follow [publishing.md](publishing.md) for staging and access checks.
