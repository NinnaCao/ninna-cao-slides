# Using the workflow across assistants

Use the whole folder in an assistant that loads Agent Skills. Load the references when the task needs more detail. Use the current environment's presentation and file tools.

When the user attaches the folder or `SKILL.md` to a chat, read the supplied instructions and apply them in that chat. If you receive the instructions as pasted text, use them directly and work from the project files and examples you can access.

- With file and code tools, use the available presentation tools for PPTX and PDF. For motion in HTML, create a self-contained deck with the available tools.
- With text output, provide a slide-by-slide draft with the message, visual direction, layout and speaking notes for each slide. Include a complete HTML code block if the user requests browser slides and a text response can accommodate it.
- If a requested export is unavailable, tell the user which deliverables you produced and give them the most useful format you can create.

The design approach comes from Visual Slides. Choose the visuals, type and compositions from the current brief. Use the examples to choose a composition that fits the audience. When the user's work is the subject, use their photographs, charts or diagrams as evidence.
